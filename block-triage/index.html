Block Triage

Which interface do you want to open?

🗂️ Local file triage
Load a GeoJSON file, review areas on a map, split/combine/keep, and remove areas you don't want (undoable) - then export the result. Nothing touches MapRoulette.
🌐 Live MapRoulette editing
Load a challenge straight from the MapRoulette API and edit its tasks live: split, combine adjacent areas, and queue-add/delete. New areas snap to road/path intersections as you draw them. Every change is applied to MapRoulette directly.
